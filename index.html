關於我

測試對我來說從來不是機械式的操作。 我習慣進入 Chrome DevTools 分析 React 組件狀態流、監控 WebSocket 封包， 從代碼層級定位問題根源——而不只是描述表面症狀。

擔任 Lead 後，我意識到最大的槓桿點不是自己測得多快， 而是把對的人放在對的位置： 誰擅長介面細節、誰更適合確認資料一致性——這些判斷讓團隊協作自然流暢。

現在，我正在把 AI 賦能帶進測試工作流： 用 Vibe Coding 開發實際可上線的 Chrome 套件， 研究 AI 驅動的自動化測試，讓重複性工作消失，讓測試覆蓋率提升。

核心強項

  • 白箱測試：DevTools、WebSocket 封包分析
  • 資料一致性：MongoDB/Redis 深度驗證
  • 壓力測試：Python 200 機器人效能壓測
  • 環境維運：Jenkins、Docker、Linux 部署
  • 流程自動化：VBA、Jira 自動化爬蟲、飛書 Workflow
  • AI 協作：Vibe Coding、Prompt Engineering

大型賽事系統壓力測試
博弈遊戲 ｜ 高併發場景
賽事系統上線前，需要確保能支撐大量玩家同時報名， 但實際環境很難模擬真實壓力。 用 Python 開發 200 具機器人並發執行壓測腳本， 同步監控後端日誌與資料庫狀態。
結果：成功支撐單場 3,000+ 人同時報名，上線後無重大事故。

跨雲端資料庫無損遷移
AWS → Aliyun ｜ 零容錯品質保證
核心後台從 AWS 遷移至 Aliyun，無任何回退機制， 一旦數據錯誤就是生產事故。 設計多層數據一致性校驗機制， 覆蓋資料庫比對、報表系統輸出驗證與業務流程端到端測試。
結果：數據庫與報表系統達成 100% 準確率轉換，零數據遺失。
