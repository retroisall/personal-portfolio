關於我

從手動測試 → Lead 管理 → AI 賦能開發，每個階段都在突破自己。

測試對我不是機械式操作。我習慣進入 Chrome DevTools 分析 React 組件、監控 WebSocket 封包，從代碼層級定位問題——而不只是描述表面症狀。

擔任 Lead 後，我發現最大槓桿點不是自己測得多快，而是 把對的人放在對的位置。誰擅長介面細節、誰更適合確認資料一致性——這些判斷讓團隊自然協作。

現在，我正在用 AI 賦能擴張測試邊界：用 Vibe Coding 開發 Chrome 套件、研究 AI 驅動的自動化測試、讓重複性工作消失。

核心強項

  • 白箱測試：DevTools、WebSocket 分析
  • 資料驗證：MongoDB/Redis 深度校驗
  • 壓力測試：Python 200 機器人併發
  • 環境維運：Jenkins、Docker、Linux
  • 流程自動化：VBA、Jira、飛書 Workflow
  • AI 協作：Claude Code、Vibe Coding
